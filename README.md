# Kosh_snowflake

Визуализация фрактала **«Снежинка Коха»** на Qt Widgets.

## Возможности

- Построение снежинки Коха с заданным числом итераций.
- Регулировка количества итераций от 0 до 10.
- Регулировка размера снежинки.
- Автоматическое центрирование рисунка в окне.
- Сглаживание линий при отрисовке.
- Отображение текущей итерации в заголовке окна.

## Требования

- CMake 3.16 или новее
- Компилятор с поддержкой C++17
- Qt 5 или Qt 6 с модулем `Widgets`
- Qt Creator — опционально
